🧠 Recuerda estas cinco ideas

  1. El router conecta tus dispositivos con Internet.
  2. Para actividades importantes, usa una conexión de confianza.
  3. Protege el Wi-Fi y la administración del router con contraseñas fuertes y diferentes.
  4. Si ves un dispositivo desconocido, primero comprueba quién es.
  5. Mantén el router actualizado y utiliza una seguridad Wi-Fi moderna, como WPA2 o WPA3 si está disponible.
